# Cathode

A total rebuild of alpha's renderer in Vulkan for **Minecraft a1.1.2_01 ONLY**.

## Credits

Special thanks to [Moehreag](https://github.com/moehreag) for
[legacy-lwjgl3](https://github.com/moehreag/legacy-lwjgl3), which made this possible.

## Setup

To use it:

1. **Set your java version to 25** in the launcher, **any other version will crash your game!**.
